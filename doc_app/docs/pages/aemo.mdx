## Key Factors

- **The domain was bounded.** Control room operations gave a specific task with a defined success
  condition, not an open-ended assistant.
- **The dataset was specified before the build.** Historical cases became the labeled set, which
  made every iteration measurable rather than anecdotal.
- **The application mattered as much as the agent.** Tooling and interface were built to make the
  agent's job possible, not bolted on afterwards.
- **Evaluation ran continuously.** A score after every iteration is what turned the build into
  hill climbing rather than guesswork.
- **Speed created the opening.** Six weeks to a working build changed the conversation before
  scepticism could set in.
- **Success compounded.** One successful PoC funded the credibility for the next two, and the three
  together opened the platform discussion.
