## What Was Learned

read-only hosted worker; isolate any later Agent Optimizer work to development.
All are **proposed, not authorized**. Keep frozen evaluation, hard refusals, SME
acceptance, immutable records and recovery at AgentCraft. Detailed reasoning and
source-backed distinctions live in FEATURES, not duplicated here.

Prospective primary metric: `engineering-effort-per-accepted-change`. No effort
measurement, evaluator or approved numeric target exists; acceptance is not ready. Future
deployment and evaluation require a new authorized increment with measurable
criteria, independent evaluation and SME acceptance.
