# Provenance

the active custom-optimizer component. Service/evaluation differed only in thread
names. Portable source removes app imports and domain-specific result/UI labels.
The app's tested draft/install/continuation helpers and strict feedback validation
were retained. Its generic reader moved into the private `_local_query` package,
exported through the canonical Python API with trusted construction-time policy.

[LICENSE](LICENSE) is the unchanged source MIT notice. The creative workflow's
[notice](src/agent_optimization/skills/creative-agent-optimization/LICENSE) is retained.
These notices do not establish rights to customer data, external research bodies,
model outputs or dependencies; each keeps its own terms.

source selection (historical-not-advertised; source reference: `provenance/skillpack-sources.json`) are historical provenance only.
