## Discovery And Limits

- Discovery used three Microsoft Learn search responses and the current Foundry navigation document; receipts are in the metadata file.
- No ranked web-search provider was configured. DuckDuckGo Instant Answer was not treated as ranked research.
- The legacy `azure/ai-foundry/toc.json` endpoint returned 404; the current `azure/foundry/toc.json` endpoint was acquired.
- W3C Trace Context and the Microsoft REST short-link were not acquired because robots policy refused this fetcher.
- Redirect chains were not exposed by the fetcher. The moved OpenTelemetry landing page is linked alongside its current repository.
- Source bodies remain in temporary internal storage. Reacquisition can return newer bytes; URL equality does not reproduce a recorded hash.
- This is a broad, bounded collection, not a claim to index every historical or future Foundry document.
