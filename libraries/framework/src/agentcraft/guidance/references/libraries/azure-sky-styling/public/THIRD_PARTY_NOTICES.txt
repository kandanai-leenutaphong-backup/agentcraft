Painterly architecture masks
===========================
Derived from public-domain images supplied by The Metropolitan Museum of Art:

Jean Laurent Legeay, Architectural Fantasy, ca. 1785-90, red chalk.
Met object 343077: https://www.metmuseum.org/art/collection/search/343077
Original: https://images.metmuseum.org/CRDImages/dp/original/DP811619.jpg
Derivative: legeay-temple.webp

Charles Michel Ange Challe, Architectural Fantasy, 18th century,
pen and brown ink with brown, gray and black wash.
Met object 343439: https://www.metmuseum.org/art/collection/search/343439
Original: https://images.metmuseum.org/CRDImages/dp/original/DT9549.jpg
Derivatives: challe-crowned-hall.webp and challe-arcade.webp

Both source records identify the works as public domain. The Met Collection API
documents corresponding images as public domain: https://metmuseum.github.io/
Metadata records are released under Creative Commons Zero (CC0 1.0); the images
are public domain. Neither instrument licenses the publisher's own web pages.
Modifications: selected architectural crops, tonal extraction into transparency,
feathered boundaries, source colors removed, and runtime azure tinting.
The artists and museum do not endorse this application.
