# Foundry Agent Evaluation, Optimization, And Observability

Research collection started 2026-09-15. Documentation only: no library implementation,
dependency installation, Azure deployment, or paid evaluation run is included.

## Questions

- How are Foundry agents evaluated offline, during development, and in production?
- Which built-in evaluators, custom graders, datasets, and safety assessments are available?
- Which optimization workflows change prompts, agent configuration, or model weights?
- Which metrics, traces, logs, dashboards, and alerts expose agent behavior and quality?
- Which SDKs and REST APIs support these workflows, and where do current and classic
  Foundry contracts differ?
- Which permissions, costs, regions, preview limitations, and data-handling constraints
  affect adoption?

## Evidence Policy

Prefer Microsoft Learn documentation, official API references, and Microsoft-maintained
SDKs and examples. Distinguish documented behavior from locally or cloud-verified behavior.
Record source URLs, retrieval dates, redirects, and unavailable material. Treat examples
as examples, not as proof of production guarantees or authorization.

Keep original research and source metadata in this directory. Third-party documents remain
publisher-owned and are acquired only into an internal temporary reference cache. Source
